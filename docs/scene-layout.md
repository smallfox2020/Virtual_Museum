# 场景布局规格 ——「光影长廊，楚韵洄游」

> 这是空间设计的唯一依据。改布局前先读它，改完把实际坐标写回这里。
> 目标：打破「火柴盒 + 干瘪网格」，让六个展厅成为有情绪起伏的剧场。
> 情绪曲线：震撼（序厅）→ 朝圣（曾侯乙墓）→ 升华（编钟）→ 理性（青铜器）
> → 浪漫（楚文化）→ 沉淀（陶瓷）。

## 必须保留的既有设计（不要动）

- 外墙、隔墙、门洞位置、窗户（窗户只在序厅与编钟厅，各 4 个）
- 墙面材质（四个变体同一米白底，只有细节差别）
- 隔墙不做墙裙（门洞处会与白墙咬合闪）—— 只有外墙有墙脚
- 小地图、朗读器、进房提示

## 空间骨架（不可变）

```
ROOM        48 × 80 m，高 14 m，墙厚 0.6
序厅        x ∈ [-24, 24]   z ∈ [18, 40]    高 8.5   出生点 (0, 33)
长廊        x ∈ [ -6,  6]   z ∈ [-18, 18]   高 7
青铜器厅    x ∈ [ 6, 24]    z ∈ [ 0, 18]    高 6     门在 (6, 9.5)
陶瓷厅      x ∈ [ 6, 24]    z ∈ [-18, 0]    高 6     门在 (6, -9.5)
曾侯乙墓厅  x ∈ [-24, -6]   z ∈ [ 0, 18]    高 6     门在 (-6, 9.5)
楚文化厅    x ∈ [-24, -6]   z ∈ [-18, 0]    高 6     门在 (-6, -9.5)
编钟厅      x ∈ [-24, 24]   z ∈ [-40, -18]  高 14    开口在 z = -18, x ∈ [-6, 6]
编钟本尊    (0, -29)
```

四条侧厅 18 × 18 m，门开在内墙正中。展台半径 0.62 m，碰撞半径 0.94 m，
玩家半径 0.42 m ⇒ **任意两个障碍物之间要留 ≥ 1.0 m 净距**才走得过去。

## 各厅设计

### 1. 序厅 —— 漏斗式神秘开场

- **倾斜石柱阵**：三对石柱，`x = ±5.2`，`z = 24 / 30 / 36`，
  高 5.5 m、半径 0.45 m，向中轴内倾 0°（`rotation.z = ∓0.12`）。
- **弧形回形墙**：两道弧形墙收成漏斗，把视线压向长廊入口。
  圆弧中心 `(±30, 18)`、半径 23 m，角度取 15° ~ 50°，
  即东侧从 `(7.8, 24)` 走到 `(15.2, 35.6)`，西侧镜像。
  墙高 4.5 m、厚 0.35 m，两端加垂直短肢形成「回」的钩子。
- 入口区 `z ∈ [18, 24]` 必须完全留空（两个游戏台在这里）。
- 平面图展板在 `(0, 39.7)`，两件展品在 `(±4.6, 39.0)`。
- 长凳挪到 `(±15, 22)` 与 `(±15, 31)`，花器在 `(±11.5, 38.6)`。

### 2. 曾侯乙墓展厅 —— 地下宫殿的环绕朝圣

- **青铜巨柱**：`(-11, 4) (-11, 14) (-19, 4) (-19, 14)`，
  半径 0.7 m、高 5.8 m，青铜材质 + 鎏金箍。
- **放射状回形墙**：中心方形回环墙（外 6 × 6、厚 0.35、高 2.8），
  四角留缺口形成「回」；四条放射短肢从环墙四角指向房间四角。
- 展品维持 `(-18.8, 2.9/9.5/16.1)` 与 `(-11.4, 2.9/16.1)`。

### 3. 编钟厅 —— 半圆剧场式聚焦

- **韵律柱**：以编钟 `(0, -29)` 为圆心、半径 13 m 的两段圆孤柱列，
  角度 `25°~70°` 与 `110°~155°`（**中间 70°~110° 留空，不挡入口中轴**），
  每段 4 根，柱高 8 m、半径 0.55 m，柱身带鎏金箍。
- 展品 `(-19, -25)`、`(19, -25)` 保持在半径 13 之外。

### 4. 青铜器厅 —— 硬朗的珍珠项链

- **方形柱阵**：四根方柱（0.7 × 0.7、高 3.6）放在回形墙四角。
- **十字回形墙**：中心方形回环墙（外 4 × 4、厚 0.35、高 2.8），
  位于 `(15.1, 9.5)`，四角留缺口。
- 展品在 `x = 11.4` 与 `18.8` 两列：环墙外缘 13.1 与展台外缘 12.02
  之间只有 1.08 m 净距 —— **这是下限，不能再缩**。

### 5. 楚文化展厅 —— 蜿蜒流淌的浪漫梦境

- **红黑木柱**：`x = -11.4` 与 `x = -18.8` 两列，红漆柱与黑漆柱交替 ——
  半径 0.2 m、高 4.2 m，每列 4 根（`z = -16.1 / -9.5 / -2.9 / -3.8` 中的四选）。
- **流线型回形墙**：两道 S 形曲墙（各 4 段折线近似），
  墙高 3.2 m，从 `(-9, 4)` 蜿蜒到 `(-19, 14)` 一侧，另一道镜像。
- 展品在 `(-18.8, -16.1/-9.5/-2.9)` 与 `(-11.4, -16.1/-2.9)`。

### 6. 陶瓷厅 —— 阶梯递进的沉淀

- **细密格栅柱**：`x = +11` 一列 5 根细柱（半径 0.22 m、高 4 m），
  间距 0.55 m，形成格栅；另一列在 `x = +19`。
- **错层矮墙**：三道横向矮墙（高 1.1 / 1.5 / 1.9 m 递进），
  位于 `z = -4 / -9.5 / -15`，宽 4 m，中间留 1.4 m 过道。
- 展品在 `(18.8, -16.1/-9.5/-2.9)` 与 `(11.4, -16.1/-2.9)`。

### 7. 长廊 —— 光影长廊

- 两侧各 8 幅书画立轴保持原位（`SCROLL_SLOTS`），
  但要在两个门洞（`z = 6.9~12.1` 与 `-12.1~-6.9`）之外。
- 顶部加光影节奏：沿中轴每 6 m 一组暗色叠涩梁，压出光影层次。

## 实施纪律

1. **一次改一个厅，改完立刻验证**，不要六个厅一起动。
2. 每个厅改完必须跑：分区正确性、穿模检查、可达性、门口路径、异常。
3. 弧墙用**圆碰撞体链**近似（间距 0.3 m、半径 0.25 m），
   不要引入旋转盒碰撞体 —— 碰撞解算器只支持轴对齐盒和圆。
4. 展品坐标由 `ARTIFACTS` 的 `tag` 决定归属厅，**不要按数组下标推断**。
5. 构筑件全部放进 `src/structures.js`，`museum.js` 只写「哪个厅摆什么」。
